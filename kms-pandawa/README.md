# KMS Bank Sampah Pandawa Berjaya

Sistem Informasi & Knowledge Management untuk Bank Sampah Pandawa Berjaya, RW 02 Banyumanik, Kota Semarang. Dibangun sebagai implementasi Pilar **Smart Environment** dalam konsep **Smart City** Kota Semarang.

---

## 🎯 Latar Belakang & Tujuan

Bank Sampah Pandawa Berjaya menghadapi 4 bottleneck operasional (Bab II.4):
1. **Dua sistem pencatatan** (Google Form + buku besar) berjalan paralel tanpa integrasi → risiko selisih saldo
2. **Keterbatasan transparansi** nasabah tidak bisa cek saldo/riwayat mandiri
3. **Risiko hilangnya institutional memory** saat regenerasi pengurus (SOP, kontak pengepul, harga jual bersifat lisan)
4. **SOP pemilahan tidak terdokumentasi** tertulis → relawan baru berisiko salah memilah

**Solusi KMS** mengintegrasikan siklus **Capture → Store → Share → Apply** (model SECI Nonaka & Takeuchi) ke dalam satu aplikasi web progresif (PWA) yang:
- Offline-first untuk operasional di lapangan
- Real-time sync via Firebase Firestore
- Akses nasabah via link publik (tanpa login)
- Broadcast WhatsApp terintegrasi

## 🏗 Arsitektur Teknologi (To-Be)

### Lapisan Bisnis
- Proses inti: Setor → Timbang → Catat → Jual
- Pencatatan **terpusat** (bukan bercabang 2 jalur)
- Knowledge flow: SOP & Harga → Digital → Akses relawan/nasabah

### Lapisan Aplikasi
| Modul | Fungsi | Actor |
|-------|--------|-------|
| **Scanner** | Scan QR nasabah, input berat, offline-ready | Petugas Penimbangan |
| **Transaksi** | CRUD transaksi lengkap, cetak struk | Petugas Pencatatan |
| **Nasabah** | CRUD nasabah, QR portal, riwayat | Admin |
| **Katalog Harga** | Master harga per kategori & pengepul | Admin |
| **SOP Digital** | Dokumentasi pemilahan, versioning, tag | Admin |
| **Laporan** | Filter tanggal/kategori/pengepul, export | Admin |
| **Broadcast WA** | Template pesan, target filter, log kirim | Ketua/Admin |
| **Portal Nasabah** | Saldo, riwayat, SOP, share link (public) | Nasabah |

### Lapisan Data
- **Firebase Firestore** (Spark plan): real-time, offline SDK, auth
- Collections: `users`, `nasabah`, `transaksi`, `katalogHarga`, `sop`, `broadcastLog`
- **IndexedDB** (via `idb`): antrean operasi offline → background sync

### Lapisan Teknologi
- **PWA**: installable, service worker, cache strategi
- **WhatsApp Gateway**: Fonnte/Wablas REST API (~Rp50k/bln)

## 🚀 Quick Start

### Prasyarat
- Node.js 20+
- Firebase project (Spark plan)
- Fonnte/Wablas account (optional, untuk WA broadcast)

### Instalasi

```bash
# 1. Clone & install dependencies
git clone <repository-url>
cd kms-pandawa
npm install

# 2. Generate PWA icons (sekali saja)
node generate-icons.mjs

# 3. Konfigurasi environment
cp .env.example .env.local
# Edit .env.local dengan kredensial Firebase & Fonnte
```

### Konfigurasi Firebase

1. Buat project di [Firebase Console](https://console.firebase.google.com)
2. **Authentication** → Sign-in method → Enable **Anonymous**
3. **Firestore Database** → Create database → **Start in test mode**
4. Copy config ke `.env.local`:
   ```env
   VITE_FIREBASE_API_KEY=your-api-key
   VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your-project-id
   VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
   VITE_FIREBASE_APP_ID=1:123456789:web:abcdef123456
   ```
5. (Opsional) Deploy security rules:
   ```bash
   firebase deploy --only firestore:rules,firestore:indexes
   ```

### Konfigurasi WhatsApp (Fonnte)
```env
VITE_FONNTE_API_KEY=your-fonnte-key
VITE_FONNTE_BASE_URL=https://api.fonnte.com
```

### Environment Variables Lainnya
```env
# Demo/Usability Test Mode
VITE_DEMO_MODE=false

# Google Form Survey URL for usability testing
VITE_SURVEY_URL=https://forms.gle/your-form-id

# App Configuration
VITE_APP_NAME=Bank Sampah Pandawa Berjaya
VITE_APP_URL=https://pandawa-berjaya.vercel.app
```

### Development

```bash
npm run dev          # Start dev server (http://localhost:5173)
npm run build        # Production build (output: dist/)
npm run preview      # Preview production build
npm run lint         # Oxlint (fast linter)
```

## 📱 PWA Features

| Feature | Implementation |
|---------|----------------|
| **Installable** | `manifest.webmanifest` + service worker |
| **Offline-first** | IndexedDB queue → auto-sync on reconnect |
| **Background Sync** | `navigator.serviceWorker.sync.register('pandawa-sync')` |
| **Cache Strategy** | QR images: CacheFirst (30 hari); Fonts: StaleWhileRevalidate |
| **Shortcuts** | "Scanner Penimbangan" → `/scan`; "Transaksi Baru" → `/transaksi` |
| **Icons** | 72-512px generated via Sharp, maskable |

### Testing PWA
```bash
npm run build
npm run preview
# Buka di Chrome DevTools → Application → Service Workers
# Test offline: Network → Offline → coba scan/transaksi
```

## 🔄 Offline Flow (Capture → Sync)

```
User Action (Offline)
       │
       ▼
┌──────────────────┐
│ addTransaksi()   │──► Local state update (optimistic UI)
│ status: 'pending'│
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ queueOperation() │──► IndexedDB (idb) store
│ type: transaksi  │
└────────┬─────────┘
         │
     [Network Online]
         │
         ▼
┌──────────────────┐
│ syncPendingOps() │──► Process queue sequentially
│ (auto-triggered) │     Mark 'synced' + syncedAt
└──────────────────┘
```

**Kode kunci** (`src/lib/offline.ts`):
- `queueOperation()` — simpan ke IndexedDB
- `getQueuedOperations()` — baca antrean
- `syncPendingOperations()` — proses sinkronisasi
- `onOnlineChange()` — listener otomatis

## 🔧 Troubleshooting

| Masalah | Solusi |
|---------|--------|
| `btn` class not found | Pastikan `index.css` di-import di `main.tsx`, gunakan Tailwind v4 syntax |
| QR scanner tidak jalan di HP lama | Fallback input manual kode (N001, N002) sudah tersedia |
| WA broadcast gagal | Cek API key Fonnte, pastikan nomor nasabah format +62xxx |
| Offline tidak sync | Cek `navigator.onLine`, buka DevTools → Application → IndexedDB |
| Build chunk >500kB | Code-split: `const ScannerPage = lazy(() => import('./pages/ScannerPage'))` |
| TypeScript errors | Run `npm run lint` untuk cek oxlint, pastikan TS config sesuai |
